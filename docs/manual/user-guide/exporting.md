# Exporting Results

EVA can export processed recordings and analysis summaries for downstream workflows.

## Processed Recordings

EVA can export processed data back to MFF, including:

- Continuous data
- Epoched data
- Averaged data

## Figures And Views

Use figure export when a waveform, topography, or average view is needed for communication, review, or reporting.

## Health Metrics

EVA can save JSON snapshots for channel-health and segment-health metrics. These exports can support later model training or audit trails.

## Export Checklist

- Confirm the active processing history.
- Confirm channel inclusion and interpolation decisions.
- Confirm filter and reference choices.
- Confirm epoch and baseline settings for averaged exports.
- Keep original raw data unchanged and clearly separated from processed exports.
