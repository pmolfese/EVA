# Glossary

**Average reference**  
A reference scheme where each channel is expressed relative to the average across selected channels.

**Bad channel**  
A channel marked as unreliable for review or analysis.

**Butterfly plot**  
An overlaid display of many channel waveforms, often used to inspect global response patterns.

**Epoch**  
A time window cut from continuous data around an event.

**ICA**  
Independent component analysis, a decomposition method often used to identify artifacts such as blinks or muscle activity.

**ICLabel**  
A classifier that estimates likely labels for ICA components.

**Interpolation**  
Replacement of a bad channel using information from surrounding channels and sensor geometry.

**MFF**  
EGI/MagStim recording package format.

**Notch filter**  
A filter used to reduce a narrow frequency band, commonly line noise.

**Segment health**  
EVA's explainable quality summary for a time interval.

**Topomap**  
A scalp map showing the spatial distribution of signal values across electrodes.
