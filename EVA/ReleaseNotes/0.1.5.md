This release substantially expands EVA's ERP and single-trial analysis tools,
adds a new ICA solver, and improves the averages workspace.

## Single-trial analysis

- **Woody alignment** — estimate and correct trial-by-trial latency shifts using
  correlation, peak, or matched-wavelet alignment.
- **RIDE decomposition** — separate stimulus-locked, latency-variable, and
  optional response-locked components.
- **CWT ridge analysis** — detect low-SNR peaks with continuous wavelets and align
  trials using dynamic time warping, curve registration, or MAP estimation.
- Inspect alignment results as animated waveform overlays and aligned averages.
- Export Woody shifts and RIDE latencies for further analysis.
- Optional wavelet denoising improves alignment when single-trial signal-to-noise
  is low.
- CWT results can include functional PCA summaries of residual trial variability.

## ICA

- Added the **Picard-O** ICA solver, including reference cross-checks and
  integration with the component-exploration workflow.

## Averages and epoch quality

- The averages workspace calculates several signal-to-noise measures from
  retained trials, including plus/minus averaging, baseline-relative SNR,
  standardized measurement error, and split-half reliability.
- Average and butterfly views gained clearer latency markers and improved event
  and log presentation.

## Artifact correction

- Added experimental **per-electrode OBS alignment**, allowing artifact epochs to
  be aligned separately for each channel before residual PCA correction.

## Other changes

- Reorganized the PSA and single-trial interfaces.
- Consolidated the wavelet implementations used by reduction, denoising, and
  latency analysis.
- Corrected an MFF writer issue.
- Expanded in-app methodological documentation and third-party notices.
