This release expands physiological and scanner-artifact correction, improves
health-guided epoch review, and adds more capable batch processing.

## CWL and cardiac correction

- **CWRegrTool-compatible correction** — a dense delay embedding with overlapping
  Hann-tapered fits provides a path designed to follow CWRegrTool behavior.
- **EVA Fast CWR** — a faster regularized sliding-window CWL solver is available
  as an alternative.
- **Configurable sample rate** — CWL fitting can run at a lower rate using
  windowed-sinc or block-average anti-aliasing, then reconstruct the estimated
  correction at the recording's original sampling rate.
- **Pulse-Ox gating** — pulse-ox peaks can be used as a cardiac detection source.

## MRI gradient correction

- Expanded FASTR-family donor selection and validation.
- Added FACET-compatible options for the 30-artifact template window, OBS epoch
  sampling, and slice-rate ANC high-pass behavior.
- Improved FARM correlation-based and Moosmann motion-informed template selection.
- Added AFNI and BERGEN/SPM motion-file handling and selectable translation-only
  or six-parameter motion metrics.

## Artifact cleaning

- Added more faithful AMRI-style donor and alignment behavior for averaging-based
  artifact correction.
- Artifact windows can follow each event's measured duration.
- Added correction detrending and configurable edge tapering to reduce
  discontinuities at window boundaries.
- Applied corrections can be shown or hidden during visual review.

## Segment health and epoching

- Segments can be manually labeled **Good** or **Bad**.
- Labeled-bad segments can be excluded automatically from category averages.
- Per-epoch bad-channel interpolation and rejection diagnostics are recorded in
  the averaging summary.
- Segment health can run automatically after segmentation.

## Batch processing and tooling

- Clearer per-file and per-step progress for background batch processing.
- Improved replay controls and saved processing provenance.
- Initial standalone EVABIDS conversion and inspection utilities.
