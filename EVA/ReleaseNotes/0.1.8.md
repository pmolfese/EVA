This release brings the simulator into the app as a real window rather than a
separate command-line tool, adds a time-frequency lens alongside the existing
Average/Trials views, teaches EVA to read FIF files natively, and introduces
**EVAResolve**, a companion app for bringing MNE- and OpenMEEG-built head
models into EVA's own forward pipeline.

## New: Simulator Studio and the Source Simulator window

EVASimulate's generation engine and forward model now live inside EVA's own
app module, reachable from two windows:

- **Simulator Studio** (File ▸ New ▸ Simulated Recording) generates a full
  synthetic MFF recording from inside the GUI — per-band background
  amplitudes, coordinate import, and preset scenarios in Generate mode, plus
  Score, Sweep, and Group modes for batch validation work that previously
  meant leaving the app and scripting the CLI by hand.
- **Source Simulator** (File ▸ New ▸ Source Simulator) is a from-scratch
  authoring and localization workspace: place dipoles on a glass-brain view
  with orthogonal projections and ⌥-drag rotation, see the BEM head model as
  a wireframe, watch the live in-process forward topomap update as you move a
  source, author an activation timeline, and generate a real scalp-EEG MFF
  recording without round-tripping through a file. White/pink background
  noise at a target SNR and blink/saccade/EMG/BCG artifacts can be layered in
  under that noise with full timing truth, alongside clean/noisy/truth-sidecar
  export and a live SNR/correlation-vs-truth readout.

  The same window also does the inverse problem: **single-dipole fitting**
  (a batched-grid position search plus a closed-form moment solve),
  **multi-dipole fitting** (one dipole per placed source, with deflation
  initialization and joint-objective coordinate descent), and a
  **Scherg/Berg spatiotemporal fit** for simultaneous sources with distinct
  timecourses, toggled between an instant fit at one latency and an
  interval fit across a window. A **Fit mode** switch turns the same window
  toward real recordings — right-click a butterfly or topography view in the
  main waveform window and choose "Fit Source Model" to hand every open
  condition, plus the file's real montage, to a shared-geometry fit that
  reports whether the source model actually differs between conditions.

  Fitted sources overlay on the main viewer as purple diamonds, run off the
  main thread with a progress spinner, and report position error in mm,
  orientation error in degrees, goodness-of-fit, and an SVD spectrum (a
  cheap read on how many distinct sources the data actually supports). The
  main waveform view also gained an ⌥-drag on any topomap to scrub its
  playhead directly.

## New: Event-related time-frequency

A **Time-Frequency** view tab joins Average and Trials, computing ERSP,
inter-trial phase coherence (ITPC), and a DPSS multitaper spectrogram per
epoch — each cross-checked against MNE-Python to better than 1e-6 agreement.
Results export as byte-identical NPY arrays for downstream analysis in Python,
or as a tidy scalar CSV for spreadsheet-style summaries.

## New: native FIF support, and EVAResolve for BEM import

EVA now reads `.fif` files directly — including a Finder QuickLook preview —
without a conversion step.

**EVAResolve** is a new, separate app bundled alongside EVA
(`gov.nih.nimh.cmn.eva.resolve`) whose one job is bringing externally-built
head models into EVA's forward pipeline: import a boundary-element model from
MNE or OpenMEEG, or a finite-element model from DUNEuro, and resolve it into
the same `EVACore/Core/Forward` geometry that EVA and EVASimulate already
share. This is deliberately scoped to import — segmentation, meshing, and
solving stay in the tools that already do that well.

## New: QuickLook previews across more neuroimaging formats

Finder previews and thumbnails now cover GIFTI surface meshes (with an
interactive 3D turntable — drag to orbit, scroll or pinch to zoom), NIfTI and
MGH volumes, DICOM images, and CIFTI connectivity matrices, alongside the
existing MFF and FIF previews.

## Also new

- **EVACore** is now a real shared module: forward models
  (spherical/ellipsoidal/BEM), channel geometry, DSP, and MFF I/O compile
  once and are used by EVA, EVASimulate, and EVAResolve alike, rather than
  each maintaining its own copy.
- **Waveform display scales** — the on-screen amplitude and sweep-speed
  sliders' physical-unit readout is now rate-independent.

## Fixes

- **Single Trial Analysis** No longer crashes or misbehaves when a category
  has no good trials, or fewer than two.
- **Cardiac (BCG) review** Fixed a display issue in the detection panel.

## Documentation

The [ROADMAP](https://github.com/pmolfese/EVA/blob/main/ROADMAP.md) now
tracks two additional programs — the in-app Simulator and event-related
Time-Frequency — alongside the existing EVA Core and EVASimulate tracks.
