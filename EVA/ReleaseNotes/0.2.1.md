This release brings a larger artifact definition and review workspace, an
interactive channel-by-epoch Decision Matrix, and a redesigned PSA configuration
sheet. It also adds BioSemi BDF import and recording-specific electrode-location
imports, and lowers the minimum system requirement to macOS 15 on Apple silicon.

## Define, review, and clean artifacts

**Define**, **Review**, and **Clean** now share one artifact window. Definition
controls sit beside a larger waveform or topography preview, with independently
scrolling columns. Review uses an artifact source list, a central preview canvas,
and a settings inspector; Clean provides the artifact treatment list and options.

- Browse detected examples as **Waveforms** or **Topomaps**, eighteen at a time.
  Inspect individual events with the top three or five affected channels and
  adjustable surrounding context. Keyboard navigation and Space to toggle
  Include/Exclude support reviewing many examples.
- Review **Spatial groups** to separate families of scalp patterns, then inspect
  **Waveform subgroups** within a family. Choose a target family count or a
  cohesion threshold, inspect outliers, and optionally group globally inverted
  maps together. Preview grouping does not apply cleaning or change decisions.
- Move selected events or families into separately named artifact classes with
  their own references and treatments. Dragging spatial cards onto the artifact
  sidebar creates a new class. Threshold blink and eye-movement events can also
  be reassigned between their categories.
- Preview automatic Include/Hold/Exclude rules before applying them. Manual
  choices are preserved by default, and references can be explicitly rebuilt
  from included examples.
- Select multiple artifacts in the source list to change their treatment
  together. Different existing treatments are shown as **Mixed**.

Spatial grouping and waveform analyses run in the background and reuse cached
results when their inputs are unchanged. Contextual help explains grouping,
review decisions, scores, and correction windows. Similarity scores describe
shape agreement; they are not probabilities that an event is an artifact.

## PSA configuration and artifact handling

The **PSA Segmentation** sheet now pairs an editable **Events & Categories**
table with a resizable, independently scrolling inspector. Event selection,
counts, category names, and DIN timing-marker controls stay together. Pooled
groups and regex categories appear in the same table and remain visible while
filtering event codes.

The inspector includes an epoch-window preview, artifact handling, channel
interpolation, and output settings. All collapsible sections start expanded.
The artifact rejection list and optional rejection time window are now directly
inside **Artifact Handling**, replacing the small options pop-up. Existing
uncorrected-versus-any-artifact rules, Bad-label exclusions, and rejection-window
bounds remain available.

## Review epochs in the Decision Matrix

The Decision Matrix brings channel and epoch evidence together before averaging.
It can open as a floating window above the epoched waveform, or as a guided
review sheet when **Average by category** and **Use Decision Matrix** are enabled.

- Click a cell to inspect its evidence in a resizable details pane. In the
  floating matrix, selection also navigates to the corresponding waveform.
- Review health summaries, artifact exclusions, correction status, and proposed
  interpolation. Hover summaries explain channel and epoch indicators.
- Adjust **Max interpolated / epoch** and the minimum/maximum **Amplitude (µV)**
  review cutoffs to update decisions and retained-trial counts using cached
  evidence. Other health, artifact, spatial, and manual constraints still apply.
- Select ranges or rectangles to act on cells or whole epochs. Sorting preserves
  the underlying trial identities. Option-click an epoch's health band in the
  waveform to edit the same review decisions.
- Keep rejected trials available for inspection while excluding them from
  averages. Reopening review after averaging returns to the complete source
  epoch set, allowing a revised average.

Hiding the floating window preserves the review, and its size and placement are
remembered. Artifact-rule edits reuse existing health evidence; changes to the
signal or processing refresh the affected evidence. Matrix construction and
health processing also include memory and performance improvements.

## BioSemi BDF import

Open or drop **BDF and continuous BDF+** recordings directly. EVA reads signed
24-bit samples, applies per-channel calibration, and separates recognizable
physiological channels from scalp EEG. Ambiguous EXG channels remain available
for manual role assignment.

Status triggers use the lower 16 bits, retaining event onsets and durations;
equipment-status bits do not create experimental events. BDF+ annotations and
mixed channel sample rates are supported. Recordings with actual gaps or
overlapping records are refused rather than presented as continuous data.

BDF recordings can be processed and exported to MFF with events, physiological
channels, and processing history. BDF does not supply electrode coordinates;
provide an appropriate location file when needed. BDF export is not included.

## Import electrode locations

**Channels → Import Locations…** accepts BrainVision **BVEF**, MFF
**coordinates.xml**, and MFF **sensorLayout.xml** files for the focused recording.
Review matches by electrode name or channel number before applying them.

Location imports preserve recorded samples, labels, and channel order. A 3D
import updates both the scalp layout and interpolation geometry; existing
repairs are recalculated against the new geometry. A 2D-only import does not
enable spherical-spline interpolation or retain unrelated old 3D coordinates.
Unmatched and radius-zero electrodes receive no invented positions.

Export a new MFF to retain the imported locations and their audit record.
Unnumbered BVEF REF/GND entries do not shift signal channels, and importing
locations does not automatically change EEG/physiological channel roles.

## macOS 15 and Apple silicon

EVA now targets **macOS 15 or later** and **Apple silicon Macs**. The app,
Quick Look extensions, and simulator helper build for arm64 with a macOS 15.0
minimum. The Release build has been verified; runtime testing on an actual
macOS 15 machine remains outstanding. macOS 14 is not supported.
