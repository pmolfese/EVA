This release adds GPU compute paths for the wavelet and gradient engines,
switches the wavelet reducer to empirical Bayes thresholding, substantially
rebuilds the FASTR corrector, and relicenses EVA as a U.S. Government public
work.

## Wavelet: empirical Bayes thresholding

EVA now uses **Johnstone & Silverman (2005) empirical Bayes** threshold selection
with the quasi-Cauchy prior as the wavelet reducer's default threshold model.

This corrects a real methodological problem. MATLAB `wdenoise`'s documented
`'DenoisingMethod','Bayes'` behavior maps to this estimator, **not** BayesShrink,
despite the shared word. In a subtract-the-thresholded-reconstruction pipeline
the two adapt in opposite directions: BayesShrink's gate collapses on
artifact-inflated EEG bands and ends up classifying nearly the whole signal as
artifact. Empirical Bayes keeps only sparse outliers.

The implementation was written independently from the published mathematics and
validated numerically against the authors' R package.

> **Behavior change:** saved pipelines that relied on the previous default will
> clean less aggressively than before. This is the intended correction, but it
> will change your results — re-check any in-flight analyses.

The robust universal threshold remains available, and every threshold picker now
carries a one-line description of what the model actually does.

## Wavelet reducer

- **Biorthogonal families** — true `bior4.4` and `bior6.8` filter banks with exact
  linear phase, alongside `coif4`, `sym4`, and `db4`.
- **Local vs. global thresholds** — keep one threshold per level across the
  recording, or re-estimate in overlapping windows so quiet and noisy stretches
  each get their own noise floor.
- **Detrending**, on by default, so the transform's periodic boundary doesn't read
  a start-to-end offset as a large spurious seam artifact.
- **Skipped fine levels** — detail levels sitting entirely inside a low-pass
  filter's stopband can be excluded. Those bands hold only roll-off residue, which
  otherwise drives their noise estimate toward zero and gets subtracted wholesale.
- **Analysis range** — restrict reduction to a span of the recording, so a
  contaminated tail can't dominate thresholds, the variance-retained figure, or
  candidate ranking. Samples outside the span pass through untouched.

## Wavelet artifact explorer

- **Candidate classification** — detected candidates are typed as Ocular, Muscle,
  Channel-local, Movement, or Unclassified.
- **Scalogram popover** — a time-frequency power view for any candidate, answering
  "what does this actually look like to the wavelet?"
- **Sortable candidate table** — sort by rank, peak time, duration, score, peak
  channel, level, contributing channels, or type.
- **Opt-out selection** — every candidate is included by default; unchecking and
  re-applying updates the same artifact definition instead of stacking duplicates.
- **Faster previews** — hover previews are computed concurrently right after a
  scan, so opening one is a lookup rather than a fresh decomposition.
- Detection now runs at 500 Hz by default (250 Hz put most muscle activity above
  Nyquist), with an optional full-rate pass for fast transients.

## GPU acceleration

Metal compute paths were added for three engines, each opt-in and each falling
back to the CPU automatically when Metal is unavailable:

- the wavelet decompose → threshold → reconstruct chain,
- FASTR gradient correction,
- average-artifact gradient removal.

GPU results are computed in single precision where the CPU path uses double, so
they agree closely but not bit-for-bit.

## FASTR and gradient correction

- **New template schemes** — FARM (average the most-correlated epochs; robust to
  motion) and Moosmann (average volumes whose head position is most similar,
  using realignment parameters), alongside the existing neighbor-averaging default.
- **Motion metric** — choose translation-only (BERGEN-faithful) or all six
  parameters with rotations converted to millimeters.
- **Chunked OBS** — the residual PCA is recomputed every 60 s by default, matching
  FASTR's reference design, rather than once across the whole recording.
- **Motion file trimming** — drop volumes from the start or end of a loaded motion
  file when it disagrees with the EEG's TR count, including a one-click fix from
  the mismatch warning. No need to re-export from AFNI.

## Epoching

- **Regex event categories** — sub-select a category out of a single event code's
  individual events by matching a regular expression against each event's
  description. Category names can reference capture groups, so one rule such as
  `n2_(\w+)` → `n2_$1` fans out into `n2_nov`, `n2_rep`, and so on.
- **Windowed artifact rejection** — optionally restrict rejection to a sub-window
  of the epoch, so a blink at 750 ms in a −100…800 ms epoch need not cost the
  trial. Off by default; the whole epoch counts, as before.

## Other changes

- **Wavelet artifact cleaning** — a new per-event wavelet method that corrects each
  event from its own time-frequency content, with no donor events or shared basis
  required. Well suited to the one-off transients the Explorer finds.
- **R-wave width** — ECG detection now measures each R deflection's width directly
  on the trace and records it as the event's duration, so detections can be checked
  against the ECG or PNS channels.
- **Progress reporting** — filtering and gradient correction now show staged
  progress rather than a bare spinner.
- Segment health now runs automatically after segmentation by default.
