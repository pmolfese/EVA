---

This release improves BCG review, adds built-in update checking, and makes EVA
behave more like a document-based Mac application.

## BCG detection

- **Algorithm comparison** — evaluate the available BCG detection methods without
  changing the recording. The comparison reports the number of detected events
  and estimated heart rate for each runnable method.
- **Explanatory controls** — contextual help covers BCG algorithms, channel
  selection, thresholds, cardiac ranges, PCA options, QRS lag, and CWL settings.
- **Artifact windows** — BCG detections carry an explicit duration, making the
  marked interval more useful for review and cleaning.
- Improved BCG detection and preview performance.

## Application integration

- Opening an MFF recording from Finder, or using **Open With EVA**, now sends it
  through the same validated import path as the Open panel and drag and drop.
- Added **Check for Updates**, including support for GitHub prereleases.

## Other changes

- Refined segment-health behavior and waveform artifact marking.
