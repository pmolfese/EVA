The first tagged version established EVA as a native macOS environment for
inspecting, cleaning, and analyzing electrophysiology recordings.

## Recording and visualization

- **Recording import** — native EGI/MagStim MFF reading, with import paths for
  BrainVision, EDF, Persyst, and BESA recordings.
- **Interactive waveform display** — multichannel traces with event tracks, time
  and amplitude scaling, channel controls, and user markers.
- **Waveform-linked topographies** — inspect the scalp distribution at a selected
  point without leaving the recording view.
- **Recording tools** — combine recordings, manage channels, and export processed
  channel data.

## Signal processing

- Band-pass and line-noise filtering, average reference, downsampling, and
  spherical-spline channel interpolation.
- MRI gradient-artifact correction, ECG/QRS detection, BCG detection, PNS import,
  and early CWL support.
- Long operations run asynchronously with progress reporting so the waveform
  remains responsive.

## Artifact review and correction

- **User-defined artifacts** — create detection templates from a waveform or
  scalp topography and scan the recording for similar events.
- **Artifact cleaning** — preview and apply regression, averaging-based, OBS, and
  SSP/PCA corrections.
- **Wavelet tools** — explore and reduce transient artifacts in the time-frequency
  domain.
- **ICA and ICLabel** — decompose the recording and classify components using the
  bundled Core ML ICLabel model.

## Data quality

- **Explainable channel health** — score channels using amplitude, noise, drift,
  clipping, spectral, and neighborhood measures, with the contributing metrics
  kept visible.
- **Segment health** — review good, watch, and poor intervals and inspect the
  measurements behind each result.
- Export health measurements and labels as JSON for later model development.

## Epoching and analysis

- Event-based segmentation, baseline correction, category averaging, and average
  reference.
- Butterfly plots, overlaid-category views, and early single-trial amplitude and
  latency measurements.
- Continuous, epoched, and averaged MFF export.

## Workflow

- Batch processing and replay of recorded processing steps.
- Confirmation before closing a modified recording.
- A processing log that keeps applied transformations visible and auditable.
