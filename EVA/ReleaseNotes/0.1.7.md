title: REWIND undo/redo, a clean-room gradient engine, and new averaged-data figures
---

This release adds real undo/redo history to the waveform view, replaces EVA's
gradient/FASTR correction engine with a clean-room implementation, adds a set
of new figures for averaged (PSA) data plus a session-wide figure export
basket, and closes out a run of correctness fixes found while building all of
the above.

## History: undo, redo, and where a file has been

The waveform view's Queue/History popover now tracks a real processing
history, not just a readout.

- **Click forward and back** through everything you've done to a recording —
  filter, ICA, artifact cleaning, wavelet reduction, channel marks,
  segmentation — restored instantly from an in-memory snapshot rather than
  re-run.
- **Branches survive.** Widen a filter after narrowing it and both states
  still exist; the rail draws the whole tree, not just the path you're
  currently on, so a branch you left is dimmed but still there and still
  reachable.
- **Opening an already-processed file now shows its real lineage.** A
  package's own `eva.xml` is read back on open and folded in as history: a
  filtered, cleaned, interpolated file no longer reads as "raw" just because
  this session hasn't touched it yet. Steps from before this session are shown
  but not clickable — there's no snapshot to restore into, only the fact that
  they happened — which reuses the same "can't get there instantly" treatment
  every other history node already has.
- **Average referencing and baseline correction are now their own steps**
  (`reference` and `baseline`, previously buried as checkboxes inside the
  filter and PSA panels), so each is a branch you can navigate between
  instead of a setting that silently forked the step that happened to host
  it. `reference` also now records which channels were excluded from the
  average, which used to be invisible to the history entirely.

## Gradient correction: a clean-room engine

EVA's gradient artifact correction (average-artifact subtraction, FASTR-family
local templates, ANC) has been rewritten from a clean specification rather
than ported from any reference implementation, on both CPU and Metal.

Three findings came out of this work that the reference literature doesn't
address, and are now built in as safety constraints rather than left to the
user to notice:

- A template scale fitted per-epoch can absorb real brain signal that happens
  to correlate with the artifact over that short window — the default is now
  a median-smoothed fit rather than the raw one.
- Automatic OBS component removal can strip pure brain signal once template
  subtraction has already explained the artifact; a residual-energy floor now
  guards against that.
- ANC's adaptive step size needs a floor relative to the reference signal's
  own variance, not just an absolute one, or it can eat uncorrelated signal.

The previous FASTR implementation, its Metal backend, and its tests have been
removed.

## New: figures for averaged data

Several new views for looking at PSA/averaged conditions, each reusing the
existing plot renderers rather than drawing anything new:

- **Multi-Butterfly** — one all-channel butterfly plot per selected condition,
  stacked vertically, instead of one plot with every condition overlaid.
- **Filmstrip** — evenly-spaced topomaps across the whole epoch, one row per
  condition, for a fast first look before you know where the peaks are.
- **Joint markers** — an MNE `plot_joint`-style time marker with a linked,
  draggable topomap box, addable to any butterfly pane by right-click.
- **Difference waves** — condition A − condition B as a proper synthetic
  condition, so the existing butterfly, GFP, and topomap views draw it exactly
  as if it were recorded.
- **GFP strips** — Global Field Power (the standard "how much is happening,
  independent of location" summary) drawn under a butterfly plot.
- **Regex pattern helper** — a library of common patterns plus a live tester
  for the PSA regex sub-selection popover, so writing a category rule doesn't
  require already knowing regex.
- **Real axes on exported figures** — exported butterfly-style PNGs/PDFs now
  draw tick marks and labels into the image, since a static export has no
  toolbar to supply that context the way the live view does.

## New: a session-wide figure export basket

"Add to Export" on any figure's right-click menu now adds it to a persistent
basket (Window ▸ Figure Export) rather than saving it immediately. Each figure
is captured as a vector PDF and a full-quality PNG at add-time, so the basket
has no dependency on the source recording staying open, and can be reordered
and exported either as one multi-page contact sheet or as **individual PDF or
PNG files**, named `<prefix>-<N>` with `N` matching the figure's numbered
position in the basket list.

## Display scale in physical units

The waveform toolbar's Scale and Time Scale sliders now show what they mean in
the units the rest of EEG software uses — µV/mm and mm/s — next to the raw
numbers, with a popover for typing an exact value and a one-click "Clinical"
preset (7 µV/mm, 30 mm/s). Millimetres are nominal (72 points/inch) since EVA
doesn't measure the display; exported figures state the same numbers exactly,
since a PDF point is a physical unit by definition. Settings now has a default
sensitivity/sweep speed applied to newly-opened recordings.

Fixed along the way: the sweep speed silently varied by up to 25% between
files at different sampling rates, because the on-screen decimation stride is
an integer and only lands exactly on target for rates that are multiples of
200 Hz. The physical-units conversion now accounts for this per file; a
genuine fix for the underlying decimation is still open.

## Fixes

- **Command-Q** had stopped working after opening Settings — it was scoped to
  the File menu, which is torn down while Settings is frontmost. Moved to the
  App menu, where it belongs.
- **Closing the last window now quits EVA**, completing the intended flow:
  close a recording (with confirmation) → empty drop-target window → close
  that → quit. The confirmation step already existed; only the final quit was
  missing.
- **Rewinding to an earlier step used to leave things behind.** Stepping back
  from an artifact-cleaned state to a purely-filtered one could leave the
  artifact step active, and segment-quality health could report a false "all
  clean" verdict computed against a signal that had already changed under it.
  Both are fixed by resetting every setting a step's *presence* depends on,
  not just the ones with their own visible parameters.
- **Opening a file could occasionally create two windows** when launched by
  double-clicking a file in Finder; fixed by making the main window
  single-instance.
- A PSA average built entirely from a regex category rule (no source event
  code also checked directly) recorded correctly in the audit log but left no
  trace in the replayable `eva.xml` script — the export logic and the "can
  this actually run" check had silently drifted apart to check different
  things.
- A raster figure export (PNG/JPEG) didn't declare its resolution, so it was
  placed at double size by anything that opened it.
- Channel-health analysis now runs its per-channel passes concurrently.
