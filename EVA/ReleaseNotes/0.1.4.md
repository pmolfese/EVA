version: 0.1.4

title: Better waveform inspection and ocular artifact detection
---

This release makes detailed waveform review easier and improves the spatial
specificity of blink and eye-movement detection.

## Waveform inspection

- Hovering over the waveform reports the channel, amplitude, and time under the
  pointer.
- Epoched data can display both epoch-relative latency and the corresponding
  pre-segmentation recording time.
- Butterfly plots report latency directly at the cursor.

## Ocular artifact detection

- Added **derived VEOG/HEOG detection** alongside the original maximum-channel
  method.
- EVA can select appropriate frontal, superior, inferior, left, and right ocular
  channel groups from supported EGI HydroCel and GSN layouts.
- Blink detection uses a vertical ocular contrast; eye-movement detection uses a
  horizontal contrast.
- Ocular detector settings persist between sessions.
- Default artifact windows were expanded to better capture the full artifact.
- Topographic gating reduces detections whose spatial pattern is inconsistent
  with an ocular source.

## Events

- Overlapping event markers are clustered rather than drawing on top of one
  another.
- Hovering over a cluster presents the individual events so the intended marker
  can be selected.
